AI control (MCP)

Punctum can be operated by commands you give an AI assistant — for example Claude Desktop — running next to it. The assistant sees the open folder, looks at photo previews and moves the sliders, and you see every change live in the Punctum window. The connection uses the open MCP standard (Model Context Protocol), so it works with many AI apps, not only Claude.

How to connect

  1. Open Settings ▸ AI assistant and make sure AI control is on.
  2. In the list of AI apps, click Connect next to yours. Punctum adds itself to that app's configuration (the previous file is kept as a .punctum-kopia copy).
  3. Restart the AI app. "punctum" appears in its list of tools.
  4. Punctum must be open while you give commands. If it is closed, the assistant is asked to have it started.

App not on the list? Use Copy configuration and paste the entry into its MCP server settings. Apps that connect over HTTP get the address and token from the same settings page.

ChatGPT only connects to servers on the internet (HTTPS), not to programs on your computer. Punctum could be exposed through a tunnel, but that means putting the editor on the network — this is not done automatically. OpenAI users can use Codex instead, which connects locally.

What the assistant can do

  • Look around: program state, list of photos with date, camera and ISO, EXIF data and adjustments, preview (before, after, side by side, 1:1 crop), brightness statistics.
  • Navigate: open a folder and a photo, select photos by date, ISO, camera, format, whether they are edited or have a location.
  • Edit: every slider (a value or "by how much"), auto, reset, presets (including saving a new one), black & white with a filter, rotation, crop with an aspect ratio, copying adjustments to other photos, undo and redo.
  • Describe: title, comment, keywords, subject, author, copyright, date; location from coordinates or a place name.
  • Export: selected photos, with the options of the Export dialog.

Example commands

  • "Select the photos from last evening, run auto and lift the shadows a bit."
  • "Show me before and after for this photo. Is it too cold?"
  • "Look at a 1:1 crop of the face and choose the noise reduction."
  • "Apply Muted to all selected photos and add the keyword Tatras."
  • "Set the location Morskie Oko on the photos from 12 August."
  • "Export the selected photos as 2048 px JPEG with the watermark to the Publish folder."

Safety

  • Originals are never touched. Changes go into XMP files next to the photos, just like manual work, and every change can be undone. "Save to original", deleting files and changing program settings are not available to the assistant.
  • The server only accepts connections from this computer (127.0.0.1) and requires a token. You can generate a new token in the settings — connected apps pick it up automatically.
  • Previews the assistant looks at are sent to the AI service you use.
  • Looking up a place by name sends that name to OpenStreetMap.
